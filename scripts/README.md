# Scripts

This folder contains utility scripts for running and managing the application.

## Files

- **START_GYM_SYSTEM.bat** - Start the gym management system (Windows)
- **CHECK_SYSTEM.bat** - Check system requirements and dependencies (Windows)

## Usage

### Windows
Double-click the `.bat` files or run them from command prompt:
```cmd
scripts\START_GYM_SYSTEM.bat
scripts\CHECK_SYSTEM.bat
```
