  HOW TO CREATE DESKTOP SHORTCUT - Gym Management System
═══════════════════════════════════════════════════════════

Follow these simple steps to create a desktop shortcut:

─────────────────────────────────────────────────────────

METHOD 1: Using the Batch File (Recommended)
─────────────────────────────────────────────────────────

1. Right-click on "START_GYM_SYSTEM.bat" in this folder
2. Select "Send to" → "Desktop (create shortcut)"
3. Done! Double-click the desktop icon to start the system

─────────────────────────────────────────────────────────

METHOD 2: Manual Shortcut Creation
─────────────────────────────────────────────────────────

1. Right-click on your Desktop
2. Select "New" → "Shortcut"
3. In "Type the location" field, paste:
   
   D:\gym management\START_GYM_SYSTEM.bat

4. Click "Next"
5. Name it: "Gym Management System"
6. Click "Finish"

Optional: Change the icon
7. Right-click the shortcut → "Properties"
8. Click "Change Icon"
9. Choose an icon you like
10. Click "OK"

─────────────────────────────────────────────────────────

METHOD 3: Browser Bookmark (For Quick Access)
─────────────────────────────────────────────────────────

1. Start the system using START_GYM_SYSTEM.bat
2. Open your browser
3. Go to: http://127.0.0.1:8000/static/login.html
4. Press CTRL+D to bookmark
5. Name it: "Gym Dashboard"

Note: You still need to run the batch file first to start
the server, but then you can use the bookmark.

─────────────────────────────────────────────────────────

WHAT HAPPENS WHEN YOU USE THE SHORTCUT?
─────────────────────────────────────────────────────────

✓ Virtual environment activates automatically
✓ Django server starts in a new window
✓ Browser opens to the login page
✓ Credentials are displayed in the terminal
✓ System is ready to use!

─────────────────────────────────────────────────────────

TROUBLESHOOTING
─────────────────────────────────────────────────────────

Problem: Shortcut doesn't work
Solution: Make sure the path is correct. Right-click the
         shortcut → Properties → Check "Target" field

Problem: Server already running
Solution: Close the previous server window first, or just
         open the browser to http://127.0.0.1:8000/static/login.html

Problem: Port 8000 in use
Solution: Close any other programs using port 8000, or
         restart your computer
