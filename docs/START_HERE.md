## 🛠️ Server Management

### **Check if Server is Running**
The Django server should be running on port 8000. You can see it in the terminal.

### **Stop the Server**
Press `CTRL+C` in the terminal where the server is running.

### **Start the Server Again**
```bash
cd "D:\gym management"
backend\env\Scripts\python.exe backend\manage.py runserver
```

## 🔧 Troubleshooting

### **Can't Access the Dashboard?**
1. Make sure the Django server is running (check terminal)
2. Open: `http://127.0.0.1:8000/static/login.html`
3. Use credentials: `admin@example.com` / `admin@123`

### **API Errors?**
1. Check if backend is running on port 8000
2. Clear browser cache and reload
3. Check browser console for errors (F12)

### **Login Not Working?**
1. Make sure you're using the correct credentials
2. Check if the backend server is running
3. Try the admin panel: `http://127.0.0.1:8000/admin/`
